# 🏢 Northwind Technologies Enterprise Home Lab

## About This Project

This repository documents my hands-on enterprise IT home lab built while transitioning into IT Support.

The lab simulates a small company environment and includes Windows administration, Linux administration, networking, Active Directory, Microsoft 365 concepts, cybersecurity, and Help Desk troubleshooting scenarios.

The goal is to gain practical experience similar to an entry-level IT Support Technician or a Fachinformatiker für Systemintegration apprentice.
