# Docker Lab – Ubuntu Server + Nginx

## Objective

Deploy a Docker container on Ubuntu Server 24.04 LTS inside Oracle VirtualBox and publish an Nginx web server accessible from the Windows host.

## Environment

* Oracle VirtualBox
* Ubuntu Server 24.04 LTS
* Docker Engine
* Windows 11 Host

## Skills Practiced

* Installing Docker with apt.
* Managing Docker service with systemctl.
* Pulling container images.
* Running containers with port mapping.
* Viewing running and stopped containers.
* Stopping and removing containers.
* Testing container networking from Windows.
