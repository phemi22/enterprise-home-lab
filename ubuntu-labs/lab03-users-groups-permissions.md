# Lab 03 — Linux Users, Groups and Permissions

## Objective

Create Linux users, department groups, assign permissions, and secure shared folders.

## Users Created

* Sarah (Finance)
* David (HR)
* James (Engineering)
* Grace (IT)

## Groups Created

* finance
* hr
* engineering
* it

## Commands Practiced

```bash
groupadd
adduser
usermod -aG
groups
chown
chmod
su
whoami
ls -l
ls -ld
```

## Folder Permissions

Finance, HR, Engineering, and IT folders were assigned their respective groups and configured with permission `770`.

## Skills Learned

* Linux user administration.
* Linux group management.
* Ownership using `chown`.
* Permissions using `chmod`.
* Switching users with `su`.
* Verifying permissions with `ls -l`.
