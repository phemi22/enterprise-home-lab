# Lab 06 — Linux Networking Troubleshooting

## Objective

Learn networking diagnostics and DNS troubleshooting on Ubuntu Server.

## Commands Practiced

```bash
ip addr
ip link
ip route
hostname -I

ping -c 4 8.8.8.8
ping -c 4 google.com

nslookup google.com
dig google.com

traceroute google.com

curl -I https://google.com

sudo ufw status
sudo ufw allow ssh
sudo ufw enable
```

## Skills Learned

* Checking IP addresses.
* Checking network interfaces.
* Checking gateway configuration.
* Testing internet connectivity.
* DNS troubleshooting.
* Route tracing.
* HTTP testing with curl.
* Firewall troubleshooting.
