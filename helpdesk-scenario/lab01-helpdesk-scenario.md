## Help Desk Scenario

**Priority:** P3

**Issue:** VirtualBox failed to start because virtualization was disabled.

**First Checks:**

* Verified virtualization status in Task Manager.
* Verified CPU virtualization support using `systeminfo`.

**Action Taken:**

* Enabled Intel Virtualization Technology in BIOS.
* Saved BIOS configuration.
* Verified virtualization was enabled in Windows.

**Status:** Resolved.
